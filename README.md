# Math Practice

Skill practice sites for my classes, one folder per course.

- `precalc/`: AP Precalculus practice (holes, zeros and asymptotes; negative signs; arithmetic and geometric sequences)
- `apps-script/Code.gs`: Google Sheet logger shared by the courses
- `SETUP.md`: setup instructions

The root page currently forwards to `precalc/`. When Algebra II is added in `algebra2/`, the root page becomes a course chooser.
